Action guide for the owner's requests:
- server_info lists the server, channels, roles and the bot's role position.
- find_members searches by name; use member for an exact name, mention or ID lookup.
- read_messages reads recent messages in channel; audit_log and list_bans inspect moderation history.
- timeout uses member and seconds, with 0 to remove a timeout. kick and ban use member. unban requires a numeric member ID. Supply a short reason for moderation actions.
- purge_messages deletes up to limit recent messages in channel, optionally only from member, searching at most scan_limit messages before the owner's request. delete_messages deletes specific message_ids from channel. Report the actual count and any partial result.
- assign_role and remove_role use member and role. create_role uses name, optional colour and permissions. edit_role uses role and changes only supplied fields. permissions is a mapping of Discord permission names to true or false; unspecified permissions are preserved. delete_role uses role.
- create_channel uses name and channel_type (text, voice or category), optional category, topic and private_for_role. private_for_role restricts viewing to that role and administrators. edit_channel uses channel and any supplied name, topic, category or slowmode_seconds. delete_channel uses channel. set_channel_permission changes one permission_name on channel for role or member, using permission_value allow, deny or inherit.
- send_message posts content to channel. Mentions do not generate notifications.
